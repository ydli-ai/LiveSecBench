# Changelog

## [0.1.1] - 2025-12-18
- Added:
  - 并发分组执行功能，支持并行/串行混合策略，大幅提升评测效率
  - MySQL 存储支持，解决 SQLite 高并发写入锁定问题
  - 实时数据保存机制，支持断点续传和故障恢复
  - 图片输入支持（URL 和 base64 格式），支持多图片输入
  - 跨模态数据集评分适配
  - 排名变化追踪功能，支持历史排名对比
  - 模型 API 切换功能，支持动态 endpoint 配置
  - RPM/TPM/并发限制配置，精细化控制 API 调用速率
  - CoT 标签提取和输出内容分离功能
  - 上下文窗口溢出处理机制
  - 异常处理器和详细日志追踪
  - 瑞士制配对默认分组数量配置
  - 结构化文本输入格式支持
  - 按子维度提取问题和固定随机种子支持
  - 余额不足自动等待机制
  - HTTP 204/400/500 状态码处理
  - 空回答处理机制
  - 标识符日志追踪
  - 图片信息哈希计算优化
  - 参考回答保存和传递机制
  - 评分配置更新和评估 prompt 优化
  - 数据库索引长度优化

- Changed:
  - 优化 SQLite 高并发写入性能
  - 优化 TPM 限制策略，支持更精细的速率控制
  - 优化数据同步性能，支持 MySQL 批量操作
  - 优化模型回答批量操作，支持并行和串行切换
  - 优化评分模块执行效率
  - 改进日志格式和追踪能力
  - 改进响应解析特殊逻辑

- Fixed:
  - 修复 SQLite 高并发写入时的数据库锁定问题
  - 修复变量名冲突问题
  - 增强异常处理和错误恢复能力

## [0.1.0] - 2025-11-20
- Added:
  - 添加示例测试题数据及评估prompt示例
  - 完善配置说明、验证和错误提示
- Changed:
  - 改进环境变量加载逻辑，`.env` 文件优先于系统环境变量
  - 优化错误提示信息，提供更详细的调试信息
  - 更新依赖配置，明确支持 http2
- Fixed:
  - 修复环境变量在配置解析前未加载的问题
  - 修复 `pip install -e .` 安装失败的问题（添加构建系统配置）
  - 修复缺少 `h2` 包导致的 HTTP/2 支持问题
  - 改进环境变量解析的错误处理

## [0.0.1] - 2025-11-18
- Added:
  - 初始发布，包含核心评估、结果导出与 SQLite 存储

  - ELO 评分系统，支持瑞士制、循环、随机配对策略

  - Mock 端到端演示脚本
- Changed:
  - 文档：添加 `docs/RESULT_FORMAT.md` 说明输出结构
- Fixed:
  - 若干测试与依赖修复
